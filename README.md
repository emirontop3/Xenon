# Xenon

Xenon, Android üzerinde Chromium tabanlı WebView kullanan modern bir arama motoru uygulamasıdır.

## Özellikler

- Chromium motorlu WebView ile hızlı gezinme.
- URL veya arama sorgusu algılama.
- Koyu tema ve gradient tabanlı modern arayüz.
- Basit geçiş animasyonları ve ilerleme çubuğu.
- Her commit için GitHub Actions ile otomatik APK üretimi ve release yükleme.

## Lokal Derleme

```bash
gradle assembleDebug
```

APK çıktısı:

`app/build/outputs/apk/debug/app-debug.apk`
